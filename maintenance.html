Community (2026/06/14)

Voting

Main

Votes about almost anything can be requested. If you request a vote, Admins will decide wherever it should be done.

Points per vote

- Original Members (anyone who joined before March 2024) (including Admins): 2 points.

- Normal Members: 1 point.'

- Inactive Original Members: 1 point.'

- Inactive Members (anyone who has not joined the server for the past 14 days): 0.5 points.

- New Members (anyone who has become a Member in the last 30 days): 0.5 points.

Conditions

A vote will end 30 minutes after everyone has seen the vote (unless it is taking an unreasonable about of time for someone to vote, or if extra votes will not affect the final result). The results will be recorded and total points for each option will be calculated.

If there is a significant majority (20% over any other option) for one of the options then the vote will end (and that option wins).

If there is not a significant majority (go down this list until a winner is determined, and check for significant majority at the end of each)

- Redo the vote but Members will be asked to pick their second best option, then these results will be multiplied by 0.5 and added to the first vote results for each option.

- Optional: Do same as above but for third favorite and multiply by 0.25 and add to second and first options.

- Use 10% as significant majority.

- Winner is just the majority.

Notes

Round all final results up to the nearest integer before comparing results.

x% significant majority means that when decreasing the option with the most points by x%, you get an amount which is still greater than all other options.

votes which are not yes/no votes should be done as multiple choice, so Members will pick all options which they are happy with and so a majority of Members will not be inconvenienced.

Preferably, all votes should be done annonymously in something like a form. however there are some issues such as: people submiting multiple responses (this could be solved by collecting emails), and it may be inconvient for some people, also it would be annonymous to everyone except for the Owner.

Roles and Assignment (and some other information)

Admins

Admins are not exempt from any rules, they are only there to help manage the server.

An Admin's status may be removed at any time for any reason. Votes can be done to remove an Admin's status, however the final decision will still be made by the owner.

Admins will only be chosen by the owner.

Admin actions will be checked on the 20th of every month, or every friday (depending on availability). This means that logs will be read by a python script and any mentions which are not chat messages will be listed, then admins will be questions about evey occurence, if a valid reason is not given then said admin may be demoted and/or be banned.

Admins are only allowed to use their privilages to help maintain the server. Any actions done with these privilages which put themselves or other Members/Admins at an advantage over others will be considered 'Administrator Power Abuse', and will result in a ban.

Members

Anyone may join the server if they can successfully pass the details listed in the 'New Members' subsection in the 'Community Information' section.

Every application will be treated fairly unless the Applicant has been banned in the past.

If Dohst (https://github.com/dohst1) is not confident in allowing the Applicant to join, then a Community Vote and an Admin Vote will be made (both will be simple yes/no votes).

Current Members will be considered Inactive if they do not join the server for 14 consecutive days. After 30 consecutive days of innactivity, the Member will be removed due to innactivity.

For Original Members or Admins to be considered inactive, they must have not joined for 60 days (If an Admin becomes inactive then they will be demoted), and they will be removed after 90 days (including the 60 days).

Anyone removed for any reason (appart from being Permanently Banned) can rejoin at any time as any other New Member, however if you have been a Member for over 90 consecutive days then rejoining like this will not require two current Members to take responsibility for you.

Being online and not AFK for over 30 minutes in a day will count as you being active on that day.

Obviously, if there is a good reason for why you are inactive then it will be considered, but it should not really matter as it is not that serious to be removed for inactivity.

Contingencies (2026/06/14)

Backups

Schedual

Type A - A full backup of all server files, website files and member data. Backups taken on the 20th day of the 2nd month (February) and the 20th day of the 8th month (August) should never be deleted. These should be done while the server is offline. These should be saved on to DDSv1.

Type B - A full backup of all server files, website files and member data. Backups taken every 20th day of every month. These Backups should not be deleted until at least 3 months after it is taken.

Type C - A full or partial backup will be taken of server files, some website files and some Member Data. These backups will be taken every sunday, and will be deleted once the next monthly backup is taken.

Type D - An optional partial backup of server files, Website files and/or Member Data may be taken daily. These can be deleted at any time.

Usage

Backups should only be used to restore lost data. This can not be something like a player's inventory if they lost their items in lava.

This should only be used for serious cases such as if a rule is broken such as greifing, messing up a server update or a compromised host machine (see 'disruptions' subsection for more information about this last case).

Administrators

Administrators

Admins administrate the server, Website and Data. This means that they have nearly full access to everything. They help run the server.

Members who are promoted to Admin level should be undoubtly trust worthy, and capable of taking over as the server host without too many issues.

Please note that current 'Admins' are called Admins, but they are actually more like Moderators as no actual administration is being done.

If someone is chosen to become an Admin, they can decline, in this case, the next person in the list will be chosen. Anyone who declines this position should be treated fairly and not be disrespected because of it. Admins can also leave their position at any time.

If someone who has declined later wants the position then they may have it once another admin is required. (so basically everytime go down the list from the top when picking admins).
