Formatting (2026/06/14)

Voting (2026/06/17)

Main

Votes about almost anything can be requested. If you request a vote, Admins will decide wherever it should be done.

Points per vote

- Original Members (anyone who joined before March 2024) (including Admins): 2 points.

- Normal Members: 1 point.'

- Inactive Original Members: 1 point.'

- Inactive Members (anyone who has not joined the server for the past 14 days): 0.5 points.

- New Members (anyone who has become a Member in the last 30 days): 0.5 points.

Conditions

A vote will end 30 minutes after everyone has seen the vote (unless it is taking an unreasonable about of time for someone to vote, or if extra votes will not affect the final result). The results will be recorded and total points for each option will be calculated.

If there is a significant majority (20% over any other option) for one of the options then the vote will end (and that option wins).

If there is not a significant majority (go down this list until a winner is determined, and check for significant majority at the end of each)

- Redo the vote but Members will be asked to pick their second best option, then these results will be multiplied by 0.5 and added to the first vote results for each option.

- Optional: Do same as above but for third favorite and multiply by 0.25 and add to second and first options.

- Use 10% as significant majority.

- Winner is just the majority.

Notes

Round all final results up to the nearest integer before comparing results.

x% significant majority means that when decreasing the option with the most points by x%, you get an amount which is still greater than all other options.

votes which are not yes/no votes should be done as multiple choice, so Members will pick all options which they are happy with and so a majority of Members will not be inconvenienced.

Roles and Assignment (and some other information) (2026/07/06)

Admins

Admins are not exempt from any rules, they are only there to help manage the server.

An Admin's status may be removed at any time for any reason. Votes can be done to remove an Admin's status, however the final decision will still be made by the owner.

Admins will only be chosen by the owner.

Admin actions will be checked on the 20th of every month, or every friday (depending on availability). This means that logs will be read by a python script and any mentions which are not chat messages will be listed, then admins will be questioned about evey occurrence, if a valid reason is not given then said admin may be banned and/or demoted.

Admins are only allowed to use their privilages to help maintain the server. Any actions done with these privilages which puts themselves or other Members/Admins at an advantage over others will be considered 'Administrator Power Abuse', and said admin may be banned and/or demoted.

Members

Anyone may join the server if they can successfully meet the details listed in the 'New Members' subsection in the 'Community Information' section.

Every application will be treated fairly unless the Applicant has been banned in the past.

If the owner is not confident in allowing the Applicant to join, then a Community Vote and an Admin Vote will be made (both will be simple yes/no votes).

Members will be considered Inactive if they do not join the server for 14 consecutive days. After 30 consecutive days of inactivity, the Member will be removed due to inactivity. (For Original Members or Admins to be considered inactive, they must have not joined for 60 days (If an Admin becomes inactive then they will be demoted), and they will be removed after 90 days (including the 60 days).)

Anyone removed for any reason (appart from being Permanently Banned) can rejoin at any time as a New Member, however if you have been a Member for over 90 consecutive days before being removed, then rejoining like this will not require two current Members to take responsibility for you.

Being online and not AFK for over 30 minutes in a day will count as you being active on that day.

Obviously, if there is a good reason for why you are inactive then it will be considered, but it should not really matter as being removed for inactivity is not serious.

Moderators

Mods help regulate the community. This is a different role to Admins because Admins are supposed to focus more on the technical maintenance.

Mods will not have access to the Website or Data, and so do not have to be as trustworthy as Admins.

This role is currently not used. It will be used if the server gains more members to the point where it is needed.

Code of Conduct (2026/05/30) (moved here from old 'community information' main document)

Allowed Client Modifications

Anything that does not give you an unfair advantage over other players, and does not disadvantage other players is likely allowed.

Types of modifications which are allowed:

- Improvements to minecraft's game performance without making changes to it, such as mods that improve FPS, reduce stuttering, improve memory usage.

- Mods that change the look of the game without changing how the game is played.

- Increased visibility for things that already have visual indicators in vanilla minecraft.

- Decrease the visibility, or outright remove textures, as long as they do not change block properties.

If your mod does not fit into one of the above categories then you should assume that it is not allowed.

An incomplete list of mods and resource packs which are considered to give unfair advantages: hacking clients, x ray, freecam, inventory walk, world downloaders, seed finders, and so on.

Social Behavior and Online Safety

Please be respectful of other Members and Admins.

Discrimination and hate speech will not be tolerated.

Sensitive topics like politics, war and religion are not allowed.

Do not use players' real names in public content, instead, use their online name or minecraft username.

Try to avoid unnecessary conflict. If you have concerns with a Member or Admin, contact Dohst (https://github.com/dohst1) or another Admin.

Backups (2026/07/06)

Schedule

(A) - Backups taken on the 20th day of the 2nd month (February) and the 20th day of the 8th month (August). Full backup of all server files, website files and member data, all to be done while the server is offline. These should be saved on to DDSv1, and should never be deleted.

(B) - Backups taken every 20th day of every month. A full backup of all server files, website files and member data. These Backups should not be deleted until at least 3 months after they are taken.

Type C - A full or partial backup will be taken of server files, some website files and some Member Data. These backups will be taken every sunday, and will be deleted once the next monthly backup is taken.

Type D - An optional partial backup of server files, Website files and/or Member Data may be taken daily. These can be deleted at any time.

Usage

Backups should only be used to restore lost data. This can not be something like a player's inventory if they lost their items in lava.

This should only be used for serious cases such as if a rule is broken such as greifing, messing up a server update or a compromised host machine (see 'disruptions' subsection for more information about this last case).
