Details

Geyser-Fabric is no longer used on the server. Instead, Geyser-ViaProxy is used on ViaProxy, which is technically a separate program from the server. Please check the ViaProxy section for more information.

There are no required mods this season, you can join with a vanilla client. However, i recommend that you use at least the mods listed in the 'Recommended Mods' table (If you are not on 1.21.11, then you can use ViaFabric to join).

All mods are for the Fabric mod loader, and each mod is made by its respective creator (which can be found on the modrinth page of each mod).

All mods are linked to Modrinth, except for GeyserMC which is linked to GeyserMC.

Viaproxy

Link: https://github.com/ViaVersion/ViaProxy

Description (from github): Standalone proxy which allows players to join EVERY Minecraft server version (Classic, Alpha, Beta, Release, Bedrock)

This proxy is used with GeyserMC and Floodgate to allow bedrock clients (who are on the latest minecraft version) join the server (which is on minecraft 1.21.11). Geyser-ViaProxy is used on ViaProxy, which is technically a separate program from the server. However, because this is all still server sided, bedrock players will be able to join as they did before without any differences.

This program is NOT made by me, all credit for this goes to the developers on the github page.
