Features

Website Colors

You can change the color theme for the website from the 'Set Color' and 'Toggle Dark' buttons at the top of this page. Your settings will be saved for other website pages and the next time you visit this site.

Page Sections

All pages have toggleable sections, you can show and hide content by clicking on the headers (some tables can also be toggled by clicking on the header (first two rows)).

Maintenance and Contribution

Report / Request

Contribution

Only AmazonSMP Members will be allowed to contribute. If you would like to contribute to the website, please contact Dohst.

After your first contribution your name will be listed in the 'Website' section of the 'Credit' section on this page.

Privacy

This website

This website does not collect any of your data

This website only stores two peices of data on your computer's local storage, using the javascript code:

- localStorage.setItem('color_style', "dark");

- localStorage.setItem('color_style', "light");

- localStorage.setItem('color_mode', color);

This is done so that when you change the website's display color, your setting will be saved across pages

Github Pages

This website is hosted with Github. Please refer to their own privacy notice for more information about what data is collected.

https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection
